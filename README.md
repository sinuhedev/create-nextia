# create-nextia

## Go to test
```sh
npm i
node --run test:my-app
```

## Create project
```sh
npm create nextia@latest vitejs my-app-vitejs
npm create nextia@latest bunjs my-app-bunjs
npm create nextia@latest page my-page
npm create nextia@latest component MyComponent
```
